# Study X

A premium, local-first study timer and productivity workspace built for Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

## Vercel

Import this GitHub repository into Vercel. The default Next.js build settings work without environment variables or a persistent server.

## Data

Sessions, goals, tasks, habits, settings and theme preferences are stored in the browser's localStorage. Community numbers are explicitly demo data; no fake realtime statistics are presented as live data.
